# Bagception icon source art

These eighteen PNGs are the source icons specified by `docs/containers.md`. Each
is 1024 x 1024, 8-bit RGBA with a genuine transparent background. The built-in
image generation tool produced the artwork; the selected images were resized
from 1254 x 1254 with high-quality bicubic interpolation. No keyed background
was used. The images are original item renderings and do not reproduce vanilla
BG3 icons.

## Prompt set

All images used this shared direction:

> Original semi-realistic painted 3D fantasy game item icon. One isolated
> container, centered in a square, in a gentle three-quarter view from slightly
> above and in front. Tactile worn leather, cloth, wood, and dull metal as
> appropriate. Strong silhouette and broad shapes that remain readable at
> 64 x 64. Soft upper-left key light, faint cool rim light, muted earthy palette,
> and the subject's specified accent colour. Genuine transparent alpha with no
> floor or background. No text, logo, frame, slot square, shadow, watermark, or
> copied BG3 icon.

The subject instructions were:

| Icon | Subject and accent |
| --- | --- |
| Bagception | Open deep-teal travel bag with several visibly smaller bags nested inside. |
| WeaponRoll | Long oxblood leather roll with sword and dagger hilts in pockets; steel grey accents. |
| ShieldRack | Oak strap-frame holding one face-on round iron-rimmed shield. |
| ArmourTrunk | Broad dark-green banded chest with pauldron and folded cloth over the open lid. |
| JewelryBox | Small open royal-purple velvet casket with gold trim, ring, and amulet chain. |
| Quiver | Tall ochre leather quiver with bright arrow fletching above its mouth. |
| ScrollCase | Parchment-cream cylindrical case with protruding scroll and red wax seal. |
| PotionCase | Soft red padded case holding round-bellied crimson potion flasks. |
| ElixirRack | Upright cobalt-blue rack holding tall slender blue and violet vials. |
| CoatingKit | Poison-green hinged kit with green oil vial and dripping applicator. |
| GrenadeSatchel | Stout charcoal satchel with a fused bomb and orange fire flask. |
| ReagentPouch | Moss-green compartmented field pouch with herbs and mushrooms. |
| LarderPack | Wheat-gold food pack with bread loaf and wine bottle neck. |
| BookSatchel | Flat navy document satchel with book spines and a folded letter. |
| KeyRing | Large iron ring with four brass and iron keys; no bag. |
| ToolRoll | Brown and brass roll with hammer, lockpicks, shovel, and unlit torch. |
| DyePouch | Off-white cloth pouch with red, blue, yellow, and violet dye bottles. |
| OddsSack | Patched burlap sack with a gem, spoon, and candle. |

The tool roll was regenerated once because the first render had a backdrop.
The final file has transparent corners. All other final files came from their
first generated version.
