// Bagception containers. Weight 0 so the bags themselves cost nothing to carry;
// their contents weigh what they weigh. See docs/research/native-capabilities.md.

// A container's own weight cannot mask its contents. Tested at -100000: the empty
// bag read 0, and two 10 kg gems took it to 20. The clamp is per entity, so the
// container's own weight floors at zero and contents sum normally on top of it.
// Back to 0, as vanilla does for the camp supply sack.
// Both containers are sticky: they cannot be dropped, handed to another character,
// or sent to a chest. "InventoryBound" and "Unstorable" are both AttributeFlags
// values, so this is plain data on our own items and needs no Osiris and no status.
//
// InventoryBound is vanilla-proven -- GEN_INVENTORYBOUND applies it as a boost, and
// Flame Blade and Shillelagh use it to stop a conjured weapon being dropped.
// Unstorable has no vanilla user anywhere in the stats, so it is the unproven half;
// if the camp chest still accepts a bag, that is the flag that did not work.
//
// On the Potion Case this may also deliver spec sections 15 to 17 for free: an
// internal container bound to its inventory cannot be dragged out of the bag.

new entry "OBJ_Bagception_Master"
type "Object"
using "_Container"
data "RootTemplate" "856bd140-6963-4de1-9471-25440149e87d"
data "Weight" "0"
data "Flags" "InventoryBound;Unstorable"
data "StatusInInventory" "BAGCEPTION_CARRY"
data "Vitality" "-1"

new entry "OBJ_Bagception_PotionCase"
type "Object"
using "_Container"
data "RootTemplate" "8bf1ed2d-3655-415e-868e-fe3138760337"
data "Weight" "0"
data "Flags" "InventoryBound;Unstorable"
data "Vitality" "-1"
