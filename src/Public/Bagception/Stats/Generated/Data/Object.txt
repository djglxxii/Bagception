// Bagception containers. Weight 0 so the bags themselves cost nothing to carry;
// their contents weigh what they weigh. See docs/research/native-capabilities.md.

// A container's own weight cannot mask its contents. Tested at -100000: the empty
// bag read 0, and two 10 kg gems took it to 20. The clamp is per entity, so the
// container's own weight floors at zero and contents sum normally on top of it.
// Back to 0, as vanilla does for the camp supply sack.

// Every container is sticky: it cannot be dropped, handed to another character,
// sent to camp or put in a chest, and an inner bag cannot leave Bagception.
// "InventoryBound" and "Unstorable" are both AttributeFlags values, so this is plain
// data on our own items and needs no Osiris and no status.
//
// InventoryBound is vanilla-proven -- GEN_INVENTORYBOUND applies it as a boost, and
// Flame Blade and Shillelagh use it to stop a conjured weapon being dropped.
// Verified in game for every route. Unstorable has no vanilla user anywhere in the
// stats, so which of the two does which part is not isolated; both stay.
//
// The cost: InventoryBound also hides Bagception from the trade window, contents and
// all. Items are sold by taking them out first. See the decision log.
//
// This is what delivers spec sections 15 to 17 with no Osiris at all: an internal
// container bound to its inventory cannot be dragged out of the bag.
