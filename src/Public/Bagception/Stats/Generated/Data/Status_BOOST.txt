// ---------------------------------------------------------------------------
// SHIPPING CONTENT
// ---------------------------------------------------------------------------
//
// Carrying Bagception raises the carrier's capacity. This is the shipped answer to
// the weight problem, chosen over true weightlessness after measuring both.
//
// True weightlessness is achievable natively -- Weight() reaches items, is additive
// and clamps at zero -- but only as a status applied to each item on the way in and
// removed on the way out. Osiris cannot enumerate a container's contents and
// GetInventoryOwner returns only the top-level holder, so there is no way to write a
// sweep that repairs a missed removal. Correctness would rest entirely on never
// missing an egress event, and a miss permanently alters an item the mod does not
// own. See the decision log.
//
// This carries none of that risk: no per-item state, nothing to clean up, nothing
// stranded if the mod is uninstalled. It is plain data and the game owns the effect.
//
// The pattern is vanilla's own: OBJ_Tool_Shovel grants HAS_SHOVEL through
// StatusInInventory, with the same property flags used here.
//
// The multiplier is the one balance knob. Vanilla reference points:
//   Rage, Giant's Might    1.25
//   Giants_CarryCapacity   1.25 - 1.50
//   Enlarge                2.00
//   Strength elixirs       2.00 - 3.00
// 2.0 puts Bagception level with Enlarge: generous, clearly useful, not absurd.

new entry "BAGCEPTION_CARRY"
type "StatusData"
data "StatusType" "BOOST"
data "DisplayName" "hf01a477cgb6f6g4e79gb7c8g7afc675e58fc"
data "Description" "h7ed31a09gf1f4g483ag8c0ege7de68e2253e"
data "StackId" "BAGCEPTION_CARRY"
data "StatusPropertyFlags" "IgnoreResting;IgnoredByImmobilized;DisableOverhead;DisableCombatlog;ApplyToDead;DisablePortraitIndicator"
data "Boosts" "CarryCapacityMultiplier(2.0)"

// goal applies this to every item that goes into a Bagception or one of its bags, and

// Weight() is additive and clamps at zero per item, so one boost larger than any item
// zeroes it without the mod needing to know what it weighed.
