// Default contents for a newly created Bagception.
//
// Adding the internal containers with Osiris after the bag arrives leaves the
// client showing an empty bag until the next reload: the container's UI is built
// before the contents land and is not refreshed. Declaring them here instead means
// the engine creates the bag already holding them, so there is nothing to miss.
//
// Referenced from the master bag's InventoryList node in RootTemplates/_merged.lsx.
// The "I_" prefix names a stats entry, not a root template; "T_" would name another
// treasure table. Vanilla shape copied from GEN_Seashell in Shared.
//

// One subtable per container, not one subtable listing them all. A subtable rolls
// its own entries and picks according to the counts in its header, so
// `new subtable "1,1"` with two object lines under it drops ONE of the two at
// random — which is why a bag arrived holding only the Shield Rack. Separate
// subtables roll independently and each guarantees its own line. Vanilla
// GOB_Goblin_Generic uses the same shape.
//
// Every future internal container therefore adds two lines here, not one.
